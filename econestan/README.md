# اقتصادستان

یک شبیه‌ساز اقتصادی فارسی و راست‌به‌چپ با مدل ماهانه‌ی رشد، تورم، بازار ارز، بانکداری، بودجه دولت، بورس، مسکن، رویدادهای تصادفی و سرمایه‌گذاری شخصی.

## اجرا

این پروژه بدون build step و با JavaScript ماژولار نوشته شده است. برای اجرای محلی:

```bash
python3 -m http.server 4173
```

سپس `http://localhost:4173/econestan/` را باز کنید.
