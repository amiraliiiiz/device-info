# اقتصادستان

یک شبیه‌ساز اقتصادی فارسی، راست‌به‌چپ و کاملاً سمت‌کاربر؛ با مدل ماهانه‌ی رشد، تورم، ارز، بانکداری، بودجه دولت، بورس، مسکن، رویدادهای تصادفی و سبد سرمایه‌گذاری شخصی.

## اجرا

فایل `index.html` را با یک وب‌سرور ساده باز کنید:

```bash
python3 -m http.server 4173
```

سپس به `http://localhost:4173/` بروید. پروژه در مسیر `econestan/` قرار دارد و از JavaScript ماژولار بدون build step استفاده می‌کند.
